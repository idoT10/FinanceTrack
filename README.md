# מעקב פיננסי: הוראות הפעלה

האפליקציה היא אתר אחד (`index.html`) ששומר את הנתונים ב-Firebase, כך שהם מסונכרנים בין מכשירים וחיים גם אם מוחקים את Safari.
כל משתמש מתחבר לחשבון משלו ורואה רק את הנתונים שלו.

כל עוד לא הדבקתם פרטי Firebase, האפליקציה עובדת במצב מקומי (הנתונים נשמרים רק בדפדפן). אפשר לנסות אותה ככה לפני ההגדרה.

## קבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | האפליקציה עצמה |
| `manifest.webmanifest`, `icon-*.png` | מאפשרים הוספה למסך הבית כאפליקציה |
| `sw.js` | פתיחה מהירה וגם בלי אינטרנט |
| `firestore.rules` | כללי האבטחה של מסד הנתונים |

## שלב 1: יצירת פרויקט Firebase (חינם)

1. נכנסים ל-https://console.firebase.google.com ומתחברים עם חשבון גוגל.
2. לוחצים **Create a project**, נותנים שם (למשל `finance-app`). אפשר לכבות את Google Analytics.
3. בדף הפרויקט לוחצים על האייקון `</>` (Web) כדי להוסיף אפליקציית ווב. נותנים שם, **לא** מסמנים Firebase Hosting.
4. יוצג אובייקט `firebaseConfig`. מעתיקים אותו.

## שלב 2: הפעלת כניסה

ב-**Build > Authentication > Get started > Sign-in method** מפעילים:

- **Email/Password** (זו השיטה האמינה ביותר באפליקציה שמותקנת על מסך הבית באייפון, והיא גם נחוצה לווידג'טים בהמשך)
- **Google** (אופציונלי)

## שלב 3: מסד הנתונים

1. **Build > Firestore Database > Create database**.
2. בוחרים מיקום קרוב (למשל `europe-west1` או `eur3`) ומצב **Production**.
3. בלשונית **Rules** מוחקים את מה שיש, מדביקים את התוכן של `firestore.rules` ולוחצים **Publish**.

הכלל אומר: כל משתמש יכול לקרוא ולכתוב רק מסמכים תחת `users/<המזהה שלו>`.

## שלב 4: הדבקת ההגדרות

פותחים את `index.html` בעורך טקסט ומחליפים את הערכים בבלוק `firebaseConfig` (בראש הסקריפט) בערכים שהעתקתם בשלב 1.

> מפתח ה-API של Firebase לא סודי. האבטחה נשענת על כללי Firestore שהגדרתם בשלב 3, ולכן זה בסדר שהקובץ יהיה באתר ציבורי.

## שלב 5: העלאה לאינטרנט (GitHub Pages, חינם)

1. פותחים חשבון ב-https://github.com ויוצרים repository חדש (למשל `finance`).
2. מעלים אליו את כל הקבצים (**Add file > Upload files**) ושומרים.
3. ב-**Settings > Pages** בוחרים **Deploy from a branch**, הענף `main` והתיקייה `/ (root)`.
4. אחרי דקה-שתיים תקבלו כתובת בצורה `https://<שם-משתמש>.github.io/finance/`.
5. חוזרים ל-Firebase: **Authentication > Settings > Authorized domains > Add domain**, ומוסיפים `<שם-משתמש>.github.io`.
   בלי זה הכניסה תיכשל עם שגיאת "דומיין לא מורשה".

## שלב 6: התקנה באייפון

1. פותחים את הכתובת ב-**Safari**.
2. יוצרים חשבון (אימייל וסיסמה).
3. לחצן השיתוף > **הוסף למסך הבית**.

מעכשיו היא נפתחת במסך מלא כמו אפליקציה רגילה.

## שימוש עם אנשים נוספים

כל אחד פותח את אותה כתובת ויוצר חשבון משלו. הנתונים נפרדים לגמרי.

## מעבר מהמצב המקומי ל-Firebase

אם הזנתם נתונים במצב המקומי: בהגדרות לוחצים **ייצוא** כדי לשמור קובץ, ואחרי ההתחברות לחשבון Firebase לוחצים **ייבוא** ובוחרים אותו.

## גיבוי

בהגדרות יש **ייצוא** (קובץ JSON עם הכול) ו-**ייבוא**. כדאי לשמור עותק מדי פעם ב-iCloud.

## פתרון בעיות

- **"הדומיין הזה לא מורשה"**: חסר סעיף 5 בשלב 5 (הוספת הדומיין ב-Authorized domains).
- **"שיטת הכניסה לא הופעלה"**: חסר שלב 2.
- **הכניסה עם Google לא עובדת באפליקציה שעל מסך הבית**: זו מגבלה ידועה של iOS. השתמשו באימייל וסיסמה.
- **אחרי עדכון הקוד האפליקציה עדיין נראית ישנה**: סוגרים אותה לגמרי ופותחים שוב (ה-Service Worker מעדכן ברקע). אם צריך, מעלים את הערך של `CACHE` ב-`sw.js` (`finance-shell-v2` וכן הלאה).
